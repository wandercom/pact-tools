Privacy

Pact is an open-source local-first engineering tool. The package does not phone home, collect telemetry, or require an account for its core workflow.

When Pact uses an LLM provider, it does so with the provider credentials and model configuration chosen by the operator. Prompts, contracts, tests, and project artifacts remain in the operator's project directory unless the operator explicitly sends them elsewhere.

The `pact.tools` marketing site does not use analytics, tracking pixels, or third-party advertising.
